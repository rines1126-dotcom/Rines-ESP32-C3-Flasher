Privacy Policy for Rines ESP32-C3 Flasher

Effective date: November 7, 2026
Application: Rines ESP32-C3 Flasher
Package: espflasher.shizoghost.com
Developer: Rines ESP32-C3 Flasher

Rines ESP32-C3 Flasher is an Android application that allows users to flash firmware to supported ESP devices through a USB OTG connection.

1. Information and Authentication

The application provides Guest, Google, and Email authentication using Firebase Authentication.

When you use these sign-in features, Firebase may process authentication information such as your email address, account identifier, and authentication credentials. Passwords are handled by Firebase Authentication and are not stored as plain text by this application.

2. Advertising

The application integrates Google Mobile Ads (AdMob) for advertisements.

Google and its advertising services may collect or process information such as device identifiers, IP address, advertising identifiers, and ad interaction information to provide and measure advertisements.

For more information, please review Google's privacy policy: Google Privacy Policy .

3. Firmware and USB Access

Users can select firmware files from their device and transfer them to supported ESP boards through USB OTG.

Firmware files are processed locally for the flashing operation. The application developer does not receive the selected firmware files through this process.

USB communication is used to communicate with the connected ESP device during flashing.

4. Application Updates

The application can check GitHub Releases for available application updates.

When checking for updates, the application communicates with GitHub to retrieve release information. If an update is available, the application may download the APK from the project's GitHub repository.

GitHub's privacy practices are described here: GitHub Privacy Statement .

5. Local Storage

Application preferences, such as language, theme, and other settings, may be stored locally on your device.

Firmware files selected for flashing are accessed through Android's file selection system.

6. Third-Party Services

The application uses or integrates with third-party services:

  • Firebase Authentication: Firebase Privacy Information
  • Google Mobile Ads: AdMob and Google advertising information
  • GitHub: GitHub Privacy Statement

7. Children's Privacy

This application is not specifically directed toward children. We do not knowingly collect personal information directly from children.

8. Data Security

We rely on the security features of the application platform and integrated third-party services. However, no electronic storage or transmission method can be guaranteed to be completely secure.

9. Changes to This Policy

This Privacy Policy may be updated when application features or data practices change. The latest version will be published in this repository.
